# 궤도 스위치

두 궤도를 오가며 장애물을 피하는 원버튼 브라우저 게임입니다. 이 기반 브랜치에서는 게임 제목이 표시됩니다.

## 로컬 실행

Node.js 24 LTS와 pnpm 11.25.0으로 검증했습니다. 저장소 루트에서 실행합니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

터미널에 표시되는 로컬 주소를 엽니다. DEV-2의 화면 모듈은 `index.html`의 `#app`에 장착하고 DEV-3의 `src/main.ts`가 초기화 및 브라우저 루프를 연결합니다.

## 검증과 빌드

| 명령 | 결과 |
|---|---|
| `pnpm typecheck` | TypeScript 소스와 테스트의 타입을 확인합니다. |
| `pnpm test` | Vitest가 `*.test.ts` 등의 테스트를 찾아 실행합니다. 기반만 있는 단계에서는 테스트 0개를 허용합니다. |
| `pnpm build` | 타입 검사 후 정적 파일을 `dist/`에 만듭니다. |
| `pnpm preview` | 직전 빌드의 결과를 로컬 HTTP 서버에서 제공합니다. |

게임 실행 시 외부 자원을 불러오지 않도록 JS와 CSS는 빌드에 포함합니다. 로딩 후 오프라인 플레이와 재도전은 게임 통합 단계에서 검증합니다.
