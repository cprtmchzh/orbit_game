# 궤도 스위치

선택한 곡의 음높이별 레인에서 공을 위아래로 움직여 음표를 피하는 브라우저 게임입니다. 이 기반 브랜치에서는 게임 제목이 표시됩니다. 게임 규칙은 [v2 개발 계획서](orbit-switch-development-plan-v2.md)에 있습니다.

## 로컬 실행

Node.js 24 LTS와 pnpm 11.25.0으로 검증했습니다. 저장소 루트에서 실행합니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

터미널에 표시되는 로컬 주소를 엽니다. `index.html`의 `#app`은 화면 모듈 장착점입니다. 통합 단계에서 `src/main.ts`가 단일 브라우저 루프를 소유하고 오디오 모듈에서 샘플링한 곡 시각을 코어 갱신과 입력 처리에 전달합니다.

## 검증과 빌드

| 명령 | 결과 |
|---|---|
| `pnpm typecheck` | TypeScript 소스와 테스트의 타입을 확인합니다. |
| `pnpm test` | Vitest가 `*.test.ts` 등의 테스트를 찾아 실행합니다. 기반만 있는 단계에서는 테스트 0개를 허용합니다. |
| `pnpm build` | 타입 검사 후 정적 파일을 `dist/`에 만듭니다. |
| `pnpm preview` | 직전 빌드의 결과를 로컬 HTTP 서버에서 제공합니다. |

현재 진입 화면의 자원은 빌드에 포함됩니다. 곡 재생, 레인 이동, 로딩 후 오프라인 플레이와 재도전은 후속 통합 검증 대상입니다.
