# 궤도 스위치

선택한 곡의 음높이별 레인에서 공을 위아래로 움직여 음표를 피하는 브라우저 게임입니다. 기본곡은 12초 분량의 ‘유리 계단’입니다. 게임 규칙은 [v2 개발 계획서](orbit-switch-development-plan-v2.md)에 있습니다.

## 로컬 실행

Node.js 24 LTS와 pnpm 11.25.0으로 검증했습니다. 저장소 루트에서 실행합니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

터미널에 표시되는 로컬 주소를 열고 기본곡을 시작합니다. ↑·↓ 또는 W·S로 인접 레인에 이동하며, Esc로 일시정지합니다. ‘곡 추가’에서 같은 연주의 음원과 v2 차트 JSON을 선택하고 파트를 확인한 뒤 세션에 등록할 수 있습니다. 새로고침하면 로컬 파일을 다시 선택해야 합니다.

## 검증과 빌드

| 명령 | 결과 |
|---|---|
| `pnpm typecheck` | TypeScript 소스와 테스트의 타입을 확인합니다. |
| `pnpm test` | 코어·화면·통합 테스트를 실행합니다. |
| `pnpm build` | 타입 검사 후 정적 파일을 `dist/`에 만듭니다. |
| `pnpm preview` | 직전 빌드의 결과를 로컬 HTTP 서버에서 제공합니다. |

선택한 음원과 차트가 로드되면 같은 세션에서 파일을 다시 내려받지 않고 재도전합니다. 기록은 음원·차트·선택 파트·규칙 버전별로 해당 브라우저에 보관합니다. 오프라인 새로고침은 지원 범위 밖입니다.
