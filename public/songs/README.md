# 유리 계단

이 프로젝트를 위해 새로 작곡한 120 BPM, 4/4박자, 여섯 마디의 짧은 곡이다. `scripts/render-default-song.mjs`의 음표 표가 원본이다. 음원과 차트를 이 표에서 함께 생성한다. 외부 녹음·샘플·악보를 사용하지 않았다. Orbit Switch에 음원·차트·생성 스크립트를 함께 사용·수정·배포할 수 있다.

기본 파트는 멜로디 하나이며 재생 구간은 0–12초, 오프셋은 0초다. 서로 다른 MIDI 음높이 76·72·69·67·64가 위에서 아래로 다섯 레인을 이룬다. 채보를 위해 타이밍을 조정하지 않았다.

| 원본 ID | 마디·박 | 시작(초) | MIDI 음높이 |
|---|---|---:|---:|
| bar1-note1 | 1마디 1박 | 0.0 | 69 |
| bar4-note1 | 4마디 1박 | 6.0 | 67 |
| bar6-note3 | 6마디 3박 | 11.0 | 69 |

`node scripts/render-default-song.mjs`로 22,050Hz·모노·16비트 PCM WAV와 차트를 재생성한다. 차트의 `audioHash`는 완성된 WAV 바이트의 SHA-256이다.
